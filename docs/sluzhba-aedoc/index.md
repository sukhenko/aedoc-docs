# Служба AEDOC

**Служба AEDOC** — програма, яка працює у фоні на комп'ютері з обліковою системою або на касовому комп'ютері і поєднує облікову систему, еАкциз і каси ПРРО / РРО. Вона підписує документи ключем КЕП, виконує тривалі запити до еАкциз, зберігає актуальні статуси акцизних марок і відповідає касам, чи можна продати марку.

Службу ставить установник **AEDOC** (`AEDOC-<версія>.msi`), керує нею програма **AEDOC** у треї Windows (біля годинника): стан, налаштування, журнал.

## Для чого створена

Облікова система працює з еАкциз через документи: АЕД, повідомлення, запити залишків. Частину роботи зручніше й надійніше виконувати окремою програмою, яка працює постійно і не залежить від того, чи відкрита облікова система:

- підпис документів ключем КЕП — бібліотеки підпису працюють лише як окрема програма Windows;
- великі вивантаження з еАкциз (залишки акцизних марок по ЕО) — облікова система не чекає, служба доробить сама;
- каси — продаж не може зупинятися, коли облікова система оновлюється, перезапускається чи зайнята обміном.

## Що виконує

<div class="cards" markdown>

<div class="card">
<strong>Підпис КЕП</strong>
<span>Підписує АЕД, повідомлення про невідповідність та інші документи ключем обраного користувача і передає підпис в еАкциз.</span>
</div>

<div class="card">
<strong>Фонові завдання еАкциз</strong>
<span>Виконує тривалі запити до еАкциз (вивантаження залишків акцизних марок) і віддає результат обліковій системі, коли він готовий.</span>
</div>

<div class="card card--dev">
<strong>Сховище марок (MS SQL)</strong>
<span>Тримає актуальні статуси акцизних марок з облікової системи в окремій базі MS SQL — для великих обсягів і для кас.</span>
</div>

<div class="card card--dev">
<strong>Каси</strong>
<span>Каса сканує марку й штрихкод товару і за мить отримує відповідь «можна продати» або причину відмови; продаж повертається в облік з номером чека.</span>
</div>

<div class="card">
<strong>Хмара AEDOC для магазинів</strong>
<span>Каси віддалених магазинів отримують залишок своєї точки через хмару і працюють навіть без зв'язку з офісом.</span>
</div>

<div class="card">
<strong>Локальний режим</strong>
<span>Для магазину без облікової системи: служба на касовому комп'ютері сама бере залишок акцизних марок об'єкта з еАкциз.</span>
</div>

</div>

Які функції увімкнені, залежить від **режиму роботи**, який обирають під час установки.
