# Підключити офлайн клієнт і працювати з ним

Як підключити [AEDoc Офлайн клієнт для ПРРО](../kliient-prro.md) на касовому комп'ютері магазину, змінити точку чи оператора і що робити, коли каса показує попередження. Способи підключення й різниця між ними — на сторінці [Каси](index.md).

## З облікової програми (тип «Хмара»)

Підходить для віддалених магазинів з окремим інтернетом. На касі не потрібен ключ API еАкциз — касу підключають одноразовим кодом.

!!! info "Перед початком"
    - В обліковій програмі марки зберігаються в сховищі MS SQL (режим SQL, [майстер міграції](../../integratsiia/zberigannia/maister-mihratsii.md)).
    - На сервері обліку в треї AEDOC увімкнено **«Хмара»** («Налаштування» → «Хмара» → «Увімкнути хмару (каси магазинів)»).
    - На касовому комп'ютері встановлено AEDOC з роллю **«Каса: офлайн клієнт обліку марок»** ([Встановлення](../vstanovlennia.md)).

### 1. Отримати код в обліковій програмі

1. Відкрийте **«Об'єкти ЕО»** (або картку своєї організації ЕО, закладка «Об'єкти ЕО»), виділіть магазин і натисніть **«Каси точки»**.
2. **«Підключити касу»** → оберіть фіскальний номер ПРРО каси (10 цифр) зі списку або **«Ввести ФН вручну…»**.
3. Відкриється вікно **«Код підключення каси»**: код із 6 цифр, діє **15 хвилин** і лише один раз.

Якщо точку вже обслуговує інша служба або касу з цим ФН уже підключено, програма запитає, чи перехопити / перепідключити: стара каса буде відключена.

### 2. Ввести код на касі

1. На касі відкрийте трей **AEDOC** → **«Підключити точку»** (майстер «Підключення точки» відкривається й сам при першому запуску).
2. Крок **«Тип каси»** → **«Хмара»** → **«Далі»**.
3. Крок **«Код підключення»** — введіть код → **«Підключити»**.
4. Крок **«Завантаження»** — каса отримує залишок марок своєї точки. Вікно можна закрити: завантаження продовжиться.

**Результат:** вікно коду в обліковій програмі закривається саме, у списку «Каси точки» з'являється каса зі станом «зелений». На касі в треї: «✓ Підключено: точка …, ФН …».

## З еАкциз (тип «Локальна»)

Для магазину без облікової програми: [AEDoc Офлайн клієнт для ПРРО](../kliient-prro.md) сам бере залишок з еАкциз. У майстрі «Підключення точки»:

1. **«Тип каси»** → **«Локальна»**.
2. **«Ключ API»** — сервер еАкциз і ключ API з кабінету еАкциз → **«Перевірити»**. Якщо операторів кілька — оберіть свого; неактивного оператора обрати не можна.
3. **«Об'єкт»** — пошук за кодом (`15C`), адресою або типом; роздрібні об'єкти показано першими.
4. **«Підтвердження»** — перевірте оператора, точку й адресу → **«Застосувати»**.
5. **«Центр мережі»** — необов'язково: код із центру мережі, якщо магазини об'єднані в мережу. Без центру каса працює як завжди.
6. **«Завантаження»** — залишок марок вивантажується вікнами по 30 днів; потім дозавантажуються штрихкоди товарів.

Ключ API зберігається зашифрованим лише на цьому комп'ютері.

## Змінити точку, оператора або тип каси {#zminyty-tochku}

У треї каси — **«Змінити точку»**: відкриється той самий майстер з поточними значеннями.

- **Інша точка або оператор (локальна):** залишок очиститься й завантажиться заново; невідправлені й непогашені продажі зберігаються. Підключення до центру мережі доведеться повторити новим кодом.
- **Інша точка (хмара):** потрібен новий код для нової точки. Якщо на касі є невідправлені продажі старої точки, майстер попередить: з кодом іншої точки вони не будуть передані в облікову програму.
- **Інший тип каси (локальна ⇄ хмара):** служба поточного типу зупиняється, дані обох служб зберігаються. Windows попросить підтвердження прав адміністратора.

Скасування на будь-якому кроці нічого не змінює.

## Керування касами в обліковій програмі

Форма **«Каси точки»**: «ФН», «ПК», «На зв'язку», «Остання активність», «Стан», «Марок», «Черга», «Ключ до».

| Кнопка | Що робить |
|---|---|
| **«Підключити касу»** | новий код для каси |
| **«Перепідключити»** | новий код для тієї ж каси, стара відключається (заміна комп'ютера) |
| **«Відключити»** | каса перестає отримувати залишок; продажі накопичуються на касі до нового підключення |
| **«Оновити залишок повністю»** | вивантажити залишок точки заново, каси не відключаються |

Ті самі дії є на сервері обліку в треї, розділ **«Точки й каси»** — там видно всі точки й каси, локальні й хмарні.

## Каса без зв'язку і попередження {#kasa-bez-zviazku}

Каса продає й без інтернету — за останнім отриманим залишком. Продажі чекають на касі й відправляються, щойно зв'язок відновиться; в обліковій програмі марка отримує статус **«Погашено ЕМ»** з номером чека.

| Що показує каса (трей, «Стан») | Що це означає | Що робити |
|---|---|---|
| **«Працює з попередженням»**: немає зв'язку — каса працює за снимком; продажі чекають відправки | інтернет або хмара недоступні | перевірити інтернет; продажі відправляться самі |
| залишок може бути неактуальним: облікова програма не на зв'язку | облікова програма давно не робила обмін | перевірити, що облікова програма й регламентні завдання працюють |
| **«Помилка»**: залишок неактуальний — немає зв'язку довше N хв | зв'язку немає довше налаштованого часу (за замовчуванням 15 хв) | відновити зв'язок; продавати можна, але залишок застарів |
| залишок неактуальний: дзеркало заморожене | в обліковій програмі виконується [майстер міграції](../../integratsiia/zberigannia/maister-mihratsii.md) | дочекатися завершення міграції |
| ключ закінчується / ключ прострочено | строк ключа каси минає | у «Каси точки» — «Перепідключити» і новий код |
| касу відключено від центру мережі — потрібен новий код | касу відключили в центрі мережі | новий код у центрі: «Точки й каси» → «Підключити касу» |

**Повторний продаж марки** (та сама марка на двох касах) облікова програма не проводить: марка отримує статус «Порушення (подвійний продаж)», а розбіжність — у протокол обміну. Потрібно зробити повернення за одним із чеків.
