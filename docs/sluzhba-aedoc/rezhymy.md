# Режими роботи служби AEDOC

Один установник AEDOC ставиться на будь-який комп'ютер мережі; що саме працюватиме на комп'ютері, визначає **режим**, обраний під час установки. Змінити режим можна пізніше — тим самим установником.

| | Сервер обліку | Каса (хмара) | Каса (локальний режим) |
|---|---|---|---|
| Де ставиться | комп'ютер (сервер) з обліковою системою BAS і підсистемою AEDOC | касовий комп'ютер у магазині | касовий комп'ютер магазину без облікової системи |
| Що працює | служба AEDOC | клієнт каси | служба AEDOC у локальному режимі |
| Звідки залишок марок | облікова система (АЕД, обмін з еАкциз) | хмара AEDOC — залишок своєї точки | еАкциз — залишок свого об'єкта ЕО |
| Чи потрібна облікова система | так | так (на сервері обліку) | ні |
| Без зв'язку | — | каса працює: залишок з останнього оновлення, продажі чекають відправки | каса працює: залишок з останнього оновлення |
| Кількість кас | будь-яка (каси онлайн у мережі сервера) | одна чи кілька на точці | одна каса на комп'ютері |

## Сервер обліку {#server}

Основний режим. Служба працює поруч з обліковою системою і:

- **підписує документи** ключем КЕП і **виконує фонові завдання еАкциз** — завжди;
- **зберігає акцизні марки** — одним із двох способів, які обирають у «Помічнику додавання ЕО» (крок «Де зберігати акцизні марки»):

| Спосіб | Коли обрати |
|---|---|
| **У базі** — марки зберігаються в самій обліковій системі | файлова база; невеликі обсяги; немає MS SQL; каси без перевірки марок через AEDOC |
| **MS SQL** — окреме сховище марок служби | клієнт-серверна база; великі обсяги марок; потрібні каси онлайн або хмара для магазинів |

Для сховища MS SQL додатково доступні:

- **каси онлайн** — каси в мережі офісу чи магазину звертаються прямо до служби (див. [Каси](kasy/index.md#online));
- **хмара AEDOC** — каси віддалених магазинів отримують залишок через хмару (режим «Каса (хмара)» на касах).

!!! warning "Одне сховище — одна облікова база"
    Сховище MS SQL закріплюється за однією базою облікової системи. Друга база або копія бази в це сховище не пише — служба відмовить і повідомить про це в обліковій системі й у треї. Передати сховище іншій базі можна в обліковій системі: «Налаштування зберігання АЕДос» → «Зробити цю базу власником сховища».

!!! note ""
    Сховище MS SQL і хмара — для клієнт-серверних баз облікової системи. Для файлової бази (малий магазин) — спосіб «У базі».

## Каса (хмара) {#kasa}

Для магазинів, віддалених від офісу. На касовий комп'ютер ставиться **клієнт каси**: він тримає залишок акцизних марок своєї торгової точки з хмари AEDOC у пам'яті й на диску та приймає продажі каси.

- Каса працює і без інтернету: залишок — з останнього оновлення, продажі накопичуються й відправляються, коли з'явиться зв'язок.
- Підключення — **кодом**: облікова система видає 6-значний код («Об'єкти ЕО» → об'єкт → «Каси точки» → «Підключити касу»), касир вводить його в треї каси. Код діє 15 хвилин.
- На сервері обліку має бути увімкнене сховище MS SQL і хмара.

## Каса (локальний режим) {#local}

Для магазину, де немає облікової системи з AEDOC, — лише каса ПРРО. Служба на касовому комп'ютері сама:

- кожні кілька хвилин бере з еАкциз зміни залишку акцизних марок об'єкта ЕО (повне вивантаження — під час першого запуску і за потреби);
- відповідає касі, чи можна продати марку, і перевіряє в еАкциз, що продані марки погашено.

Потрібні: API-токен еАкциз економічного оператора і об'єкт ЕО (магазин) — вводяться в треї. Одна каса на комп'ютері.

## Як обрати

- Є облікова система BAS з AEDOC → на її комп'ютер — **Сервер обліку**.
- Каси в тій самій мережі, що й сервер (офіс, склад-магазин) → каси підключаються **онлайн** до сервера, на касах нічого не ставити.
- Віддалені магазини з окремим інтернетом → на касові комп'ютери — **Каса (хмара)**.
- Магазин без облікової системи, лише ПРРО → **Каса (локальний режим)**.
