# Ролі та режими роботи служби AEDOC

Один установник AEDOC ставиться на будь-який комп'ютер. Під час установки обирають **роль** комп'ютера; змінити її можна пізніше тим самим установником («Програми та компоненти» → AEDOC → «Змінити»).

| | Сервер обліку AEDoc | AEDoc Офлайн клієнт для ПРРО: з облікової програми | AEDoc Офлайн клієнт для ПРРО: з еАкциз |
|---|---|---|---|
| Роль в установнику | «Сервер обліку AEDoc» | «Каса: офлайн клієнт обліку марок» | «Каса: офлайн клієнт обліку марок» |
| Тип у майстрі трея | — | «Хмара» | «Локальна» |
| Де ставиться | комп'ютер або сервер з BAS / 1С і AEDOC | касовий комп'ютер віддаленого магазину | касовий комп'ютер магазину без облікової програми |
| Що робить | підпис КЕП, фонові завдання еАкциз, сховище марок, каси онлайн, хмара | залишок своєї точки з облікової програми, продажі — назад в облік | залишок свого об'єкта напряму з еАкциз, контроль погашення продажів |
| Чи потрібна облікова програма | так | так (на сервері обліку — сховище MS SQL і «Хмара») | ні |
| Без зв'язку | — | каса продає, продажі чекають відправки | каса продає, продажі чекають перевірки погашення |

## Сервер обліку AEDoc {#server}

Основний режим. Служба працює поруч з обліковою системою і:

- **підписує документи** ключем КЕП і **виконує фонові завдання еАкциз** — завжди;
- **зберігає акцизні марки** — одним із двох способів, які обирають у «Помічнику додавання ЕО» (крок «Де зберігати акцизні марки»):

| Спосіб | Коли обрати |
|---|---|
| **У базі** — марки зберігаються в самій обліковій системі | файлова база; невеликі обсяги; немає MS SQL; каси без перевірки марок через AEDOC |
| **MS SQL** — окреме сховище марок служби | клієнт-серверна база; великі обсяги марок; потрібні каси онлайн або хмара для магазинів |

Для сховища MS SQL додатково доступні:

- **каси онлайн** — каси в мережі офісу чи магазину звертаються прямо до служби (див. [Каси](kasy/index.md#online));
- **хмара AEDOC** — каси віддалених магазинів отримують залишок через хмару ([офлайн клієнт з облікової програми](kliient-prro.md) на касах).

!!! warning "Одне сховище — одна облікова база"
    Сховище MS SQL закріплюється за однією базою облікової системи. Друга база або копія бази в це сховище не пише — служба відмовить і повідомить про це в обліковій системі й у треї. Передати сховище іншій базі можна в обліковій системі: «Налаштування зберігання АЕДос» → «Зробити цю базу власником сховища».

!!! note ""
    Сховище MS SQL і хмара — для клієнт-серверних баз облікової системи. Для файлової бази (малий магазин) — спосіб «У базі».

## AEDoc Офлайн клієнт для ПРРО {#kasa}

Роль **«Каса: офлайн клієнт обліку марок»** — для касових комп'ютерів. Клієнт тримає на касі джерело правди про акцизні марки й відповідає касі за мить, з інтернетом і без нього. Звідки брати залишок, обирають у майстрі трея «Підключення точки»:

- **з облікової програми** (тип «Хмара») — залишок своєї точки через хмару AEDOC, підключення 6-значним кодом з облікової програми;
- **з еАкциз** (тип «Локальна») — залишок свого об'єкта напряму з еАкциз за ключем API, без облікової програми.

Як працює, що гарантує касі й чим відрізняються режими — [AEDoc Офлайн клієнт для ПРРО](kliient-prro.md); підключення — [Підключити офлайн клієнт](kasy/pidkliuchennia.md).

## Як обрати

- Є облікова програма BAS з AEDOC (навіть якщо потрібен лише підпис АЕД) → на її комп'ютер — **Сервер обліку AEDoc**.
- Каси в тій самій мережі, що й сервер (офіс, склад-магазин) → каси підключаються **онлайн** до сервера, на касах нічого не ставити ([Каси](kasy/index.md#online)).
- Віддалені магазини з окремим інтернетом → на касові комп'ютери — **офлайн клієнт з облікової програми**.
- Магазин без облікової програми, лише ПРРО → **офлайн клієнт з еАкциз**.
