# Встановити і налаштувати службу AEDOC

Службу AEDOC ставить один установник для всіх комп'ютерів — **AEDOC** (`AEDOC-<версія>.msi`). Режим комп'ютера обирають під час установки, налаштування — у програмі **AEDOC** у треї Windows.

!!! info "Перед початком"
    - Windows 10 / 11 або Windows Server з .NET Framework 4.8; права адміністратора для установки.
    - Визначтеся з [режимом роботи](rezhymy.md): сервер обліку, каса (хмара) чи локальний режим.
    - Для сервера обліку зі сховищем MS SQL — встановлений MS SQL Server (підійде безкоштовний SQL Server Express) і логін з правом створити базу.
    - Для локального режиму — API-токен еАкциз економічного оператора ([як отримати](../pershyi-zapusk/api-token.md)).

## 1. Встановити

1. Завантажте установник — кнопка **«Служба AEDOC»** у верхній смузі довідки.
2. Запустіть `AEDOC-<версія>.msi` і у вікні **«Що встановлюємо на цей комп'ютер»** оберіть режим: **«Сервер обліку»**, **«Каса (хмара)»** або **«Каса (локальний режим)»**.
3. Дочекайтеся завершення: служба запускається сама, програма **AEDOC** з'являється в треї і в меню «Пуск» і стартує разом з Windows.

**Результат:** у треї — значок AEDOC; відкрийте його — на сторінці **«Стан»** видно режим і стан служби.

## 2. Налаштувати — сервер обліку

У треї: **«Налаштування»**.

<img class="shot" style="width:89%" src="../img/trei-nalashtuvannia.png" alt="Трей AEDOC, сторінка «Налаштування» сервера обліку: 1 — блок «Сховище SQL», 2 — блок «Хмара», 3 — розгорнути «Додатково», 4 — «Зберегти»">

| Блок | Що вказати |
|---|---|
| **Сховище SQL** | лише для способу зберігання «MS SQL»: **«Увімкнути сховище SQL»**, **«Сервер SQL»** (напр. `.\SQLEXPRESS`), **«База»** (`AEDocStorage`), **«Вхід»** — обліковий запис Windows служби або логін і пароль SQL; кнопка **«Перевірити підключення»**. Базу й таблиці служба створює сама |
| **Хмара** | лише для кас віддалених магазинів: **«Увімкнути хмару»**, **«Сервер доступу»** (заповнено), **«Ключ служби»** (показується) |
| **Додатково** | **«Порт для кас»** (8766), **«Доступ кас з мережі»** і **«Токен кас»** — для кас онлайн з інших комп'ютерів (див. [Каси](kasy/index.md#online)), **«Папка inbox»** — для каси на цьому ж комп'ютері, **«Залишок застарілий після, хв»** |

Блок **«Додатково»** згорнутий — розгорніть його посиланням **«Додатково — адреси, порт, папки, інтервали»** (3):

<img class="shot" style="width:65%" src="../img/trei-dodatkovo.png" alt="Блок «Додатково»: 1 — «Доступ кас з мережі», 2 — «Токен кас» і кнопка «Згенерувати», 3 — «Папка inbox», 4 — «Зберегти»">

Натисніть **«Зберегти»** — служба перезапуститься з новими налаштуваннями.

Далі — в обліковій системі: **«Помічник додавання ЕО»** (крок «Де зберігати акцизні марки» — «У базі» або «MS SQL», [детальніше](../pershyi-zapusk/pomichnyk-eo.md)). Перенести наявні марки в MS SQL — **«Майстер міграції»** в обліковій системі.

!!! success "Сервер налаштовано, якщо"
    На сторінці **«Стан»** трея: підпис КЕП — готовий; сховище SQL — готове; «Останній обмін» — кілька хвилин тому (після першого обміну облікової системи); дзеркало марок — «актуальне».

<img class="shot" style="width:73%" src="../img/trei-stan.png" alt="Трей AEDOC, сторінка «Стан» сервера обліку: 1 — підпис КЕП готовий, 2 — сховище SQL готове, 3 — останній обмін і дзеркало марок актуальне">

## 3. Налаштувати — каса (хмара)

1. В обліковій системі: **«Об'єкти ЕО»** → об'єкт (магазин) → **«Каси точки»** → **«Підключити касу»** — з'явиться 6-значний код (діє 15 хвилин).
2. У треї каси: **«Налаштування»** → блок **«Підключення каси»** → введіть код → **«Підключити касу»**.
3. Касова програма звертається до клієнта каси за адресою `http://127.0.0.1:8766` або кладе чеки в папку `inbox` (див. [Каси](kasy/index.md)).

**Результат:** на сторінці **«Стан»** — точка, ФН каси, «Зв'язок: є», кількість марок у залишку.

## 4. Налаштувати — локальний режим

Детально, зі схемою роботи і знімками трея, — [AEDOC Клієнт для ПРРО](kliient-prro.md).

У треї: **«Налаштування»** → блок **«еАкциз»**:

1. **«Сервер еАкциз»** — «Тест» (пісочниця) або бойовий.
2. **«ЕО (UUID)»** і **«Токен еАкциз»** — з кабінету еАкциз; **«Зберегти»**.
3. **«Список об'єктів»** → оберіть **«Об'єкт ЕО»** (магазин); **«Дата початку залишку»**; **«Зберегти»**.

Служба завантажить залишок акцизних марок об'єкта (перший раз — кілька хвилин) і далі оновлюватиме його сама.

**Результат:** на сторінці **«Стан»** — кількість марок у залишку, «Останнє оновлення», «Токен еАкциз до».

## Оновлення, зміна режиму, видалення {#update}

- **Оновлення** — запустіть новий `AEDOC-<версія>.msi` поверх: режим і всі налаштування зберігаються, вікно вибору режиму не показується.
- **Змінити режим** — «Програми та компоненти» → **AEDOC** → **«Змінити»** → оберіть інший режим. Налаштування попереднього режиму зберігаються в резервній копії й повертаються, якщо режим повернути.
- **Видалення** — «Програми та компоненти» → AEDOC → «Видалити». Налаштування, дані каси, папка `inbox`, журнали, ключі й ліцензії **не видаляються**; повторна установка ставиться в ту саму папку.

??? note "Для адміністратора: тиха установка, порти, файли"
    - Тиха установка: `msiexec /i AEDOC-<версія>.msi ROLE=server /qn` (`ROLE` = `server`, `kassa` або `local`; без `ROLE` — помилка). Видалення: `msiexec /x AEDOC-<версія>.msi /qn`.
    - Папка установки — `C:\Program Files\AEDoc\`; налаштування служби — `AEDocSignService.ini` поруч з програмою (змінюйте через трей).
    - Порти: `8765` — облікова система (лише цей комп'ютер), `8766` — каси. Служба Windows — `AEDocSignService` (сервер обліку, локальний режим), клієнт каси — `MarksShopClient`; автозапуск відкладений, після збою служба перезапускається через 60 с.
    - Сторінка трея **«Служба»** — запустити / зупинити / перезапустити службу (потрібні права адміністратора), **«Журнал»** — журнал служби.
