# Встановити і налаштувати службу AEDOC

Службу AEDOC ставить один установник для всіх комп'ютерів — **AEDOC** (`AEDOC-<версія>.msi`). Роль комп'ютера обирають під час установки, налаштування — у програмі **AEDOC** у треї Windows.

!!! info "Перед початком"
    - Windows 10 / 11 або Windows Server з .NET Framework 4.8; права адміністратора для установки.
    - Визначтеся з [роллю комп'ютера](rezhymy.md): сервер обліку AEDoc чи офлайн клієнт для ПРРО на касі.
    - Для сервера обліку зі сховищем MS SQL — встановлений MS SQL Server (підійде безкоштовний SQL Server Express) і логін з правом створити базу.
    - Для офлайн клієнта з еАкциз — ключ API еАкциз економічного оператора ([як отримати](../pershyi-zapusk/api-token.md)).

## 1. Встановити

1. Завантажте установник — кнопка **«Служба AEDOC»** у верхній смузі довідки.
2. Запустіть `AEDOC-<версія>.msi` і у вікні **«Що встановлюємо на цей комп'ютер»** оберіть роль:
    - **«Сервер обліку AEDoc»** — для роботи з АЕД у BAS (підпис КЕП). Ставиться на ПК з BAS або на сервер 1С; сховище SQL і хмару для кас вмикають за потреби. Якщо вам потрібно лише підписувати АЕД у BAS — обирайте цю роль;
    - **«Каса: офлайн клієнт обліку марок»** — касовий комп'ютер магазину; тип каси («Хмара» або «Локальна») обирається в майстрі трея після установки.
3. Дочекайтеся завершення: служба запускається сама, програма **AEDOC** з'являється в треї і в меню «Пуск» і стартує разом з Windows.

**Результат:** у треї — значок AEDOC; відкрийте його — на сторінці **«Стан»** видно роль і стан служби.

## 2. Налаштувати — сервер обліку AEDoc

У треї: **«Налаштування»**.

<img class="shot" style="width:89%" src="../img/trei-nalashtuvannia.png" alt="Трей AEDOC, сторінка «Налаштування» сервера обліку: 1 — блок «Сховище SQL», 2 — блок «Хмара», 3 — розгорнути «Додатково», 4 — «Зберегти»">

| Блок | Що вказати |
|---|---|
| **Сховище SQL** | лише для способу зберігання «MS SQL»: **«Увімкнути сховище SQL»**, **«Сервер SQL»** (напр. `.\SQLEXPRESS`), **«База»** (`AEDocStorage`), **«Вхід»** — обліковий запис Windows служби або логін і пароль SQL; кнопка **«Перевірити підключення»**. Базу й таблиці служба створює сама |
| **Хмара** | лише для кас віддалених магазинів: **«Увімкнути хмару»**, **«Сервер доступу»** (заповнено), **«Ключ служби»** (показується) |
| **Додатково** | **«Порт для кас»** (8766), **«Доступ кас з мережі»** і **«Токен кас»** — для кас онлайн з інших комп'ютерів (див. [Каси](kasy/index.md#online)), **«Папка inbox»** — для каси на цьому ж комп'ютері, **«Залишок застарілий після, хв»** |

Блок **«Додатково»** згорнутий — розгорніть його посиланням **«Додатково — адреси, порт, папки, інтервали»** (3):

<img class="shot" style="width:65%" src="../img/trei-dodatkovo.png" alt="Блок «Додатково»: 1 — «Доступ кас з мережі», 2 — «Токен кас» і кнопка «Згенерувати», 3 — «Папка inbox», 4 — «Зберегти»">

Натисніть **«Зберегти»** — служба перезапуститься з новими налаштуваннями.

Далі — в обліковій системі: **«Помічник додавання ЕО»** (крок «Де зберігати акцизні марки» — «У базі» або «MS SQL», [детальніше](../pershyi-zapusk/pomichnyk-eo.md)). Перенести наявні марки в MS SQL — **«Майстер міграції»** в обліковій системі.

!!! success "Сервер налаштовано, якщо"
    На сторінці **«Стан»** трея: підпис КЕП — готовий; сховище SQL — готове; «Останній обмін» — кілька хвилин тому (після першого обміну облікової системи); дзеркало марок — «актуальне».

## 3. Каса — AEDoc Офлайн клієнт для ПРРО

На касовому комп'ютері після установки з роллю **«Каса: офлайн клієнт обліку марок»** трей сам відкриє майстер **«Підключення точки»**: оберіть, звідки брати залишок (з облікової програми — кодом, з еАкциз — ключем API), і дочекайтеся завантаження. Покроково — [Підключити офлайн клієнт](kasy/pidkliuchennia.md); як працює клієнт — [AEDoc Офлайн клієнт для ПРРО](kliient-prro.md).

Касова програма звертається до клієнта за адресою `http://127.0.0.1:8766` або кладе чеки в папку `inbox` ([API для касового ПЗ](kasy/rozrobnykam.md)).

## Оновлення, зміна ролі, видалення {#update}

- **Оновлення** — запустіть новий `AEDOC-<версія>.msi` поверх: роль і всі налаштування зберігаються, вікно вибору ролі не показується. Трей закривається і запускається сам.
- **Змінити роль** — «Програми та компоненти» → **AEDOC** → **«Змінити»** → оберіть іншу роль. Налаштування попередньої ролі зберігаються в резервній копії й повертаються, якщо роль повернути. Тип каси («Хмара» / «Локальна») змінюють у треї каси — **«Змінити точку»**.
- **Видалення** — «Програми та компоненти» → AEDOC → «Видалити». Налаштування, дані каси, папка `inbox`, журнали, ключі й ліцензії **не видаляються**; повторна установка ставиться в ту саму папку.

??? note "Для адміністратора: тиха установка, порти, файли"
    - Тиха установка: `msiexec /i AEDOC-<версія>.msi ROLE=server /qn` (`ROLE` = `server` — сервер обліку, `kassa` — офлайн клієнт; для каси можна одразу задати тип `KASSA_TYPE=local` або `cloud`, інакше його обирають у майстрі трея; без `ROLE` — помилка). Видалення: `msiexec /x AEDOC-<версія>.msi /qn`.
    - Папка установки — `C:\Program Files (x86)\AEDOC\`; налаштування служби — `AEDocSignService.ini` поруч з програмою (змінюйте через трей).
    - Порти: `8765` — облікова система (лише цей комп'ютер), `8766` — каси. Служба Windows — `AEDocSignService` (сервер обліку; офлайн клієнт з еАкциз), `MarksShopClient` (офлайн клієнт з облікової програми); на касі працює одна з двох — за типом; автозапуск відкладений, після збою служба перезапускається через 60 с.
    - Сторінка трея **«Служба»** — запустити / зупинити / перезапустити службу (потрібні права адміністратора), **«Журнал»** — журнал служби.
