# Служба підпису AEDocSignService

КЕП накладає локальна служба Windows **AEDocSignService**.

| Параметр | Значення |
|---|---|
| Порт за замовчуванням | `8765` |
| Протокол | HTTP, лише `localhost` |
| Де зберігаються ключ і токен | На боці служби |

## Як працює

1. Конфігурація передає службі дані АЕД.
2. Служба обчислює хеш і підписує його ключем КЕП.
3. Служба відправляє підпис в еАкциз і повертає результат.

Обмін асинхронний: запит одразу отримує ідентифікатор завдання, а конфігурація опитує статус, доки не надійдуть квитанції.
