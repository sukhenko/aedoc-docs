# Імпорт та оптова торгівля

Конфігурація покриває повний цикл — від ввезення акцизних марок до створення документів.

## Ланцюжок імпорту

| Етап | Що відбувається | Стан марок після етапу |
|---|---|---|
| 1. Повідомлення УІ | Замовлення марок і сплата акцизу | Неактивована → **Активована** |
| 2. Наміри ввезення | Одна партія — один намір | — |
| 3. Митне оформлення | Резервування суми, подання декларації | **Розмитнена** |
| 4. ОВП (тип 075) | Оприбуткування на склад | **На складі** |
| 5. АЕД на відвантаження | Відвантаження покупцю | — |

## Опт

Механізми для:

- АЕД на відвантаження;
- ПпН і повернень від покупців;
- інвентаризації на складах зберігання.
