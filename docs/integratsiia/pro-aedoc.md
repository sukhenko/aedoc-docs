# Що таке AEDOC

AEDOC — розширення до BAS (BAF) для роботи з акцизними електронними документами (АЕД) в еАкциз через API. Підходить усім, хто працює з підакцизними товарами: роздріб, опт, імпорт.

## Можливості

| Що | Як |
|---|---|
| Створення АЕД | З документів обліку BAS: реалізація, надходження, переміщення |
| Вхідні АЕД | Автоматичне отримання вхідних АЕД і квитанцій, створення або оновлення документів BAS |
| Підпис | КЕП усіх акредитованих КНЕДП (АЦСК), перевірка сертифікатів, позначки часу; пакетний підпис і відправка |
| Дії з АЕД | Підписати, відправити, підтвердити, відхилити — прямо з облікової програми |
| Статуси | Дорожня карта статусів: новий, відправлений, прийнятий, відхилений, анульований тощо |
| Акцизні марки | Облік і звірка марок з еАкциз, звіт про залишки марок |
| ПРРО | Інтеграція з ПРРО ВебЧек |
| Контроль | Розбіжності між документами BAS і АЕД |
