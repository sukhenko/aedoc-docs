# Варіанти інтеграції підсистеми

Підсистему AEDOC можна використовувати двома способами: як **окрему (standalone) конфігурацію** або **інтегрувати у вашу облікову систему BAS**. Обидва варіанти працюють з еАкциз і службою підпису AEDocSignService.

### 1. Standalone — окрема конфігурація

<p class="way__sub">Весь функціонал підсистеми без змін в основній конфігурації</p>

Дозволяє користуватися всім функціоналом підсистеми — обміном АЕД з еАкциз і підписом документів — **не інтегруючи її в основну конфігурацію**.

**Коли підходить:**

- **тестування** — швидко оцінити роботу з еАкциз, не чіпаючи робочу базу ([Sandbox](sandbox.md));
- **немає можливості інтегрувати** підсистему у вашу систему, але потрібен функціонал роботи з АЕД — працюєте в окремій конфігурації.

### 2. Інтеграція у вашу систему BAS

<p class="way__sub">Більше можливостей — усе в одній базі</p>

Підсистема вбудовується у вашу облікову систему BAS і працює з її документами та довідниками.

**Що додає інтеграція:**

- **Введення АЕД на підставі документів робочої бази.** Наприклад, переміщення між магазинами: на підставі переміщення АЕД створюється в кілька кліків — додаються марки, документ підписується, і переміщення готове.
- **Інвентаризація на основі залишків номенклатури.**
- **Робота у звичному інтерфейсі** — користувачі працюють в одній базі, без перемикання між програмами.

## Порівняння

| Можливість | Standalone | Інтеграція в BAS |
|---|:---:|:---:|
| Обмін АЕД з еАкциз | ✓ | ✓ |
| Підпис документів КЕП (AEDocSignService) | ✓ | ✓ |
| Введення АЕД на підставі документів робочої бази | — | ✓ |
| Інвентаризація на основі залишків номенклатури | — | ✓ |
| Робота в одній базі, у звичному інтерфейсі | окрема конфігурація | ✓ |
| Підходить для тестування | ✓ | ✓ |

## Що далі

- Перевірте, чи підтримується ваша конфігурація, — [таблиця сумісності](sandbox.md#сумісність-з-конфігураціями-bas).
- Для інтеграції передайте [технічну документацію](itdeptinfo.md) спеціалісту з вашої облікової системи (програмісту).
- Хочете спершу спробувати — почніть з [тестування в Sandbox](sandbox.md).
