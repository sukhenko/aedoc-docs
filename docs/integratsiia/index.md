# Інтеграція

Розділ для ІТ-фахівців і продакт-менеджерів, які впроваджують еАкциз у BAS/1С.

Тут будуть:

- вимоги до платформи та конфігурації;
- служба підпису AEDocSignService;
- ліцензування;
- типові рішення: роздрібна мережа, імпорт та оптова торгівля;
- інтеграція з документами вашої конфігурації.
