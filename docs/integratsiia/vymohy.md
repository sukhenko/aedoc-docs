# Вимоги

## Платформа BAS

| Параметр | Значення |
|---|---|
| Режим сумісності | Не нижче `8.3.10` |
| Рекомендований реліз платформи | `8.3.19` |
| Конфігурації на звичайних формах | У властивостях конфігурації увімкнено **«Використовувати керовані форми у звичайній прикладній програмі»** |

Підтримувані типові конфігурації та версії залежать від редакції AEDOC — уточнюйте у постачальника.

## Комп'ютер

| Параметр | Мінімум |
|---|---|
| ОС | Windows 10/11 (32/64-біт), Windows Server 2016 і новіше, з актуальними оновленнями |
| Процесор | 2 ядра, від 2,0 ГГц |
| Оперативна пам'ять | 2 ГБ (рекомендовано 4 ГБ) |
| Вільне місце на диску | 200 МБ |
| Екран | Кольоровий, від 1024 × 768 |
| Компоненти ОС | .NET Framework 4.7 і новіше |
| Регіональні налаштування | Встановлено українську мову, підтримка кирилиці |

## Мережа

!!! warning "AEDOC потребує доступу до зовнішніх ресурсів"
    - Портал і API еАкциз — `xtrace.gov.ua`
    - Сервери ДПС України — `tax.gov.ua`
    - Сервери TSP (позначки часу) вашого КНЕДП
    - Сервери OCSP (статус сертифіката) вашого КНЕДП
    - Центральний засвідчувальний орган — `czo.gov.ua`

    Список не вичерпний. Якщо КЕП видав інший КНЕДП, відкрийте також його адреси TSP, OCSP і CMP.
