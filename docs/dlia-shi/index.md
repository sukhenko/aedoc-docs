# Довідка AEDOC для ІІ-асистентів

Якщо ви користуєтесь ChatGPT, Claude, Gemini чи іншим ІІ-асистентом, дайте йому довідку AEDOC — тоді він відповідатиме про AEDOC за нашими інструкціями, а не навмання.

| Файл | Що в ньому | Коли брати |
|---|---|---|
| [llms.txt](https://dovidka.aedoc.com.ua/llms.txt) | короткий опис AEDOC і перелік сторінок довідки з адресами | асистент сам читає сайт за посиланнями |
| [llms-full.txt](https://dovidka.aedoc.com.ua/llms-full.txt) | уся довідка одним текстом: статті сайту і відповіді на часті питання | асистент не ходить в інтернет — завантажте файл у чат або в проєкт |

Файли оновлюються автоматично разом із сайтом довідки.

## Як користуватися

1. Відкрийте [llms-full.txt](https://dovidka.aedoc.com.ua/llms-full.txt) і збережіть його (Ctrl+S).
2. Додайте файл у чат асистента або в базу знань проєкту (Claude — «Project knowledge», ChatGPT — «Мої GPT» / «Проєкти»).
3. Напишіть, наприклад: «Відповідай про AEDOC лише за цим файлом і давай посилання на сторінки довідки».

!!! note "Що асистент знає і чого ні"
    Файли містять те саме, що й сайт довідки: роботу з АЕД, ПпН, УГІ, імпорт, установку служби AEDOC, каси й API для касового ПЗ.
    Даних вашої бази, ключів і стану документів в еАкциз асистент не бачить. Якщо відповідь не допомогла — пишіть у [підтримку](https://t.me/AEDocBot).

## Помилки еАкциз

Що означають відмови еАкциз і як їх виправити — сторінка [Помилки еАкциз і як їх виправити](../pomylky/index.md). Вона також входить до `llms-full.txt`: асистент підкаже рішення за текстом помилки.

## Розробникам касового ПЗ

Опис API для ПРРО / РРО (перевірка марки, фіксація продажу, коди відповідей) — сторінка [API для касового ПЗ](../sluzhba-aedoc/kasy/rozrobnykam.md). Вона також входить до `llms-full.txt`.
