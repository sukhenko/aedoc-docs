# Встановити AEDOC

AEDOC — розширення до BAS (BAF), яке працює з еАкциз через API. Для встановлення зверніться до спеціаліста, який обслуговує вашу програму.

!!! info "Перед початком"
    - Комп'ютер відповідає [технічним вимогам](../integratsiia/vymohy.md).
    - Відкрито доступ до зовнішніх ресурсів: еАкциз, ДПС, сервери вашого КНЕДП.

## 1. Встановіть службу підпису

Встановіть службу AEDOC разом із локальною службою підпису КЕП ([AEDocSignService](../integratsiia/sluzhba-pidpysu.md)).

## 2. Підключіть AEDOC до програми

У режимі **«Конфігуратор»** підключіть AEDOC до типової конфігурації одним зі способів:

- завантаженням конфігурації;
- підключенням розширення (для конфігурації «Малий бізнес»).

**Результат:** у програмі з'явилося меню **АЕДос**.

**Далі:** [Додати економічного оператора](pomichnyk-eo.md)
