# Зареєструватися економічним оператором в еАкциз

Перш ніж працювати з АЕД, суб'єкт господарювання має зареєструватися економічним оператором (ЕО) на порталі еАкциз. Реєстрація підписується кваліфікованим електронним підписом (КЕП).

| Середовище | Адреса |
|---|---|
| Робоче | [my.xtrace.gov.ua/login](https://my.xtrace.gov.ua/login) |
| Тестове (Sandbox) | [my-sb.xtrace.org.ua/login](https://my-sb.xtrace.org.ua/login) |

!!! info "Перед початком"
    - Чинний ключ КЕП суб'єкта господарювання.
    - Діюча ліцензія на торгівлю підакцизними товарами.

## 1. Оберіть ключ і тип суб'єкта

Відкрийте портал еАкциз, оберіть ключ КЕП суб'єкта господарювання і вкажіть тип суб'єкта.

<img class="shot" src="https://aedoc.com.ua/wp-content/uploads/2026/06/010-1024x683.png" alt="Портал еАкциз: вибір ключа КЕП">

<img class="shot" src="https://aedoc.com.ua/wp-content/uploads/2026/06/1-1024x672.png" alt="Портал еАкциз: вибір типу суб'єкта господарювання">

## 2. Заповніть дані

Заповніть обов'язкові поля заявки.

<img class="shot" src="https://aedoc.com.ua/wp-content/uploads/2026/06/image-7-1024x767.png" alt="Форма заявки на реєстрацію економічного оператора">

## 3. Підпишіть заявку

Оберіть ключ і підпишіть заявку.

## 4. Дочекайтеся результату

**Результат:** якщо заявку прийнято, на вашу електронну пошту прийде підтвердження реєстрації.

!!! warning "Реєстрація не пройшла?"
    Перевірте, що власник ключа має діючі ліцензії на торгівлю підакцизними товарами.
