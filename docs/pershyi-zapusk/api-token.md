# Отримати API-токен в еАкциз

Щоб AEDOC обмінювався документами з еАкциз, потрібен API-токен. Його створюють у кабінеті економічного оператора.

!!! info "Перед початком"
    - Ви [зареєстровані економічним оператором](reiestratsiia-eo.md) в еАкциз.

## 1. Увійдіть в еАкциз

Відкрийте [my.xtrace.gov.ua/login](https://my.xtrace.gov.ua/login) і увійдіть з ключем КЕП.

## 2. Відкрийте розділ API-токенів

У меню оберіть **Кабінет ЕО → API токени**.

<img class="shot" src="https://aedoc.com.ua/wp-content/uploads/2026/06/api-1024x443.png" alt="Кабінет ЕО в еАкциз: розділ «API токени»">

## 3. Створіть токен

Натисніть **«Новий токен»**, введіть назву (наприклад, `аедок1`) і натисніть **«Додати»**.

## 4. Скопіюйте токен

Система згенерує токен. Скопіюйте його одразу.

<img class="shot" src="https://aedoc.com.ua/wp-content/uploads/2026/06/image-1024x308.png" alt="Згенерований API-токен у кабінеті ЕО">

## 5. Вставте токен в AEDOC

Вставте скопійований токен у налаштування обміну з еАкциз в AEDOC.

<img class="shot" src="https://aedoc.com.ua/wp-content/uploads/2026/06/image-2.png" alt="Налаштування обміну з еАкциз в AEDOC: поле для API-токена">

**Результат:** AEDOC автоматично обмінюється даними з еАкциз.

!!! warning "Безпека"
    Зберігайте токен у надійному місці й не передавайте його стороннім. Якщо токен потрапив до чужих рук, видаліть його в розділі **API токени** і створіть новий.
